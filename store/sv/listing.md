# Lista över Chrome Web Store - engelska

## Namn

AI Usage Tracker: Quota & Limits för Claude, Codex

## Kort beskrivning

Spåra Claude och ChatGPT (Codex) sessioner och veckovis användningsgränser med ett ögonkast i ett popup-fönster och på sidan. Sekretess-först, ingen installation.

## Fullständig beskrivning

AI Usage Tracker: Quota & Limits för Claude, Codex är ett webbläsartillägg för personer som vill ha en tydligare, mer förutsägbar AI-assistentupplevelse. Spåra dina meddelandegränser, se nedräkningar i realtid och visa diskreta användningsmätare direkt på leverantörens sidor så att du kan fokusera på ditt arbete utan att plötsliga gränser.

Oavsett om du använder Claude och ChatGPT för kodning, skrivning, forskning eller djupgående problemlösning, hjälper AI Usage Tracker att minska friktionen för att träffa gränsblock och ger dig direkt kontroll över hur din kapacitet övervakas. Du väljer var överlägget ska visas och hur du spårar dina gränser.

AI Usage Tracker stöder också Kimi, MiniMax, Cursor och Xiaomi MiMo. Beroende på varje leverantörs kontodata kan den visa sessions-, vecko-, plan-, modell-, saldo- och återställningstidsdetaljer. Ingen API-nyckel eller separat inloggning krävs: tillägget läser endast från webbläsarens redan autentiserade leverantörssessioner.

Nyckelfunktioner:

- Spårning av realtidsgränser för Claude (claude.ai) och ChatGPT/Codex (chatgpt.com)
- Ett kort verktygsfältsmärke som visar din högsta nuvarande användningsprocent
- Kontextuella överlägg på sidan placerade precis bredvid chattingångar
- Hopfällbar kapselwidget i Shadow DOM för att förhindra värdsidestilkrockar
- Sessionsbaserad (5 timmar) och veckovis (7 dagar) kapacitetsövervakning
- Livenedräkningar som visar exakt när dina gränser återställs
- On-demand uppdateringsknapp och automatisk bakgrundssynkronisering var 5:e minut
- 100 % privat: läser direkt från dina egna autentiserade webbläsarsessioner

Varför användare väljer AI Usage Tracker:
- Snabb, automatiserad användningsundersökning utan manuell omladdning av sidan
- Renare gränssnitt som integreras sömlöst med AI-chattgränssnitt
- Bättre tempo för tunga kodnings-, inlärnings- eller skrivsessioner
- Säker design utan externa servrar, ingen spårning och ingen telemetri
- Enkla sidopanelskontroller med snabba aktivera/inaktivera alternativ

Perfekt för:
- Utvecklare och avancerade användare som använder Claude Code eller ChatGPT begränsar kraftigt
- Plus-, Pro- och Team-abonnenter som vill ha en tydlig läsning om sina kvoter
– Proffs och studenter som vill undvika att störa deras djupa arbetsflöde
- Alla som är trötta på att slå "du har nått din gräns" utan föregående varning

Källkod: https://github.com/cupcakedev/ai-usage-extension

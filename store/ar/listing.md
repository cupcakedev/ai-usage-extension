# Chrome Web Store Listing - Arabic

## الاسم

متتبع استخدام الذكاء الاصطناعي: الحصص والحدود لـ Claude وCodex

## الوصف المختصر

تتبّع حدود استخدام Claude وChatGPT ‏(Codex) للجلسة والأسبوع من خلال نافذة منبثقة وتراكب داخل الصفحة. خصوصية أولاً، ومن دون إعداد.

## الوصف الكامل

متتبع استخدام الذكاء الاصطناعي: الحصص والحدود لـ Claude وCodex هو إضافة متصفح لمن يريدون تجربة أوضح وأكثر قابلية للتنبؤ مع مساعدي الذكاء الاصطناعي. تتبّع حدود رسائلك، واطّلع على العدّ التنازلي في الوقت الفعلي، واعرض مؤشرات استخدام غير مزعجة مباشرة على صفحات المزوّدين لتظل مركزاً في عملك من دون الوصول المفاجئ إلى الحدود.

سواءً كنت تستخدم Claude وChatGPT للبرمجة أو الكتابة أو البحث أو حل المشكلات المعمّق، يساعدك AI Usage Tracker على تقليل الإزعاج الناتج عن حواجز الحدود ويمنحك تحكماً مباشراً في طريقة مراقبة سعتك. أنت تختار موضع ظهور التراكب وكيفية تتبّع حدودك.

يدعم AI Usage Tracker أيضاً Kimi وMiniMax وCursor وXiaomi MiMo. وبحسب بيانات الحساب المتاحة لدى كل مزوّد، يمكنه إظهار تفاصيل الجلسة والأسبوع والخطة والطراز والرصيد ووقت إعادة الضبط. لا يلزم مفتاح API أو تسجيل دخول منفصل: تقرأ الإضافة فقط من جلسات المزوّدين الموثّقة مسبقاً في المتصفح.

الميزات الرئيسية:

- تتبّع الحدود في الوقت الفعلي لـ Claude (claude.ai) وChatGPT/Codex (chatgpt.com)
- شارة في شريط الأدوات تعرض أعلى نسبة استخدام حالية لديك بلمحة
- تراكبات سياقية داخل الصفحة موضوعة بجوار حقول إدخال الدردشة مباشرة
- أداة كبسولة قابلة للطي في Shadow DOM لتجنب تعارض أنماط صفحة المضيف
- مراقبة السعة بحسب الجلسة (5 ساعات) والأسبوع (7 أيام)
- عدّ تنازلي مباشر يبيّن بدقة موعد إعادة ضبط حدودك
- زر تحديث عند الطلب ومزامنة تلقائية في الخلفية كل 5 دقائق
- خصوصية 100٪: تقرأ مباشرة من جلسات المتصفح الموثّقة الخاصة بك

لماذا يختار المستخدمون AI Usage Tracker:
- استطلاع سريع وآلي للاستخدام من دون إعادة تحميل الصفحات يدوياً
- واجهة أنظف تتكامل بسلاسة مع واجهات دردشة الذكاء الاصطناعي
- تنظيم أفضل للوتيرة أثناء جلسات البرمجة أو التعلّم أو الكتابة المكثفة
- آمن حسب التصميم: لا خوادم خارجية ولا تتبع ولا قياس عن بعد
- عناصر تحكم بسيطة في اللوحة الجانبية مع خيارات سريعة للتفعيل أو التعطيل

مثالي لـ:
- المطورين والمستخدمين المتقدمين الذين يستخدمون حدود Claude Code أو ChatGPT بكثافة
- مشتركي خطط Plus وPro وTeam الذين يرغبون في معرفة واضحة لحصصهم
- المحترفين والطلاب الذين يريدون تجنب مقاطعة تدفق عملهم العميق
- كل من سئم من ظهور «لقد وصلت إلى الحد» بلا تحذير مسبق

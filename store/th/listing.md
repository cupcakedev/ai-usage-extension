# รายชื่อ Chrome เว็บสโตร์ - อังกฤษ

## ชื่อ

ตัวติดตามการใช้งาน AI: โควต้าและขีดจำกัดสำหรับ Claude, Codex

## คำอธิบายสั้น ๆ

ติดตามเซสชันของ Claude และ ChatGPT (Codex) และขีดจำกัดการใช้งานรายสัปดาห์ได้อย่างรวดเร็วในป๊อปอัปและโอเวอร์เลย์บนหน้า ความเป็นส่วนตัวต้องมาก่อน ไม่มีการตั้งค่า

## คำอธิบายแบบเต็ม

ตัวติดตามการใช้งาน AI: โควต้าและขีดจำกัดสำหรับ Claude, Codex เป็นส่วนขยายเบราว์เซอร์สำหรับผู้ที่ต้องการประสบการณ์ผู้ช่วย AI ที่ชัดเจนและคาดเดาได้มากขึ้น ติดตามขีดจำกัดข้อความของคุณ ดูการนับถอยหลังแบบเรียลไทม์ และแสดงมาตรวัดการใช้งานที่ไม่เกะกะโดยตรงบนหน้าผู้ให้บริการ เพื่อให้คุณสามารถมุ่งความสนใจไปที่งานของคุณโดยไม่ถึงขีดจำกัดกะทันหัน

ไม่ว่าคุณจะใช้ Claude และ ChatGPT ในการเขียนโค้ด การเขียน ค้นคว้า หรือการแก้ปัญหาเชิงลึก AI Use Tracker จะช่วยลดอุปสรรคในการเข้าสู่ขีดจำกัด และช่วยให้คุณสามารถควบคุมวิธีการตรวจสอบความสามารถของคุณได้โดยตรง คุณเลือกได้ว่าจะให้โอเวอร์เลย์ปรากฏที่ใดและติดตามขีดจำกัดของคุณอย่างไร

ตัวติดตามการใช้งาน AI ยังรองรับ Kimi, MiniMax, Cursor และ Xiaomi MiMo ขึ้นอยู่กับข้อมูลบัญชีของผู้ให้บริการแต่ละราย มันสามารถแสดงรายละเอียดเซสชัน รายสัปดาห์ แผน รูปแบบ ยอดคงเหลือ และเวลารีเซ็ตได้ ไม่จำเป็นต้องมีคีย์ API หรือการเข้าสู่ระบบแยกต่างหาก: ส่วนขยายจะอ่านจากเซสชันของผู้ให้บริการที่ผ่านการตรวจสอบสิทธิ์แล้วของเบราว์เซอร์เท่านั้น

คุณสมบัติที่สำคัญ:

- การติดตามขีดจำกัดแบบเรียลไทม์สำหรับ Claude (claude.ai) และ ChatGPT/Codex (chatgpt.com)
- ป้ายแถบเครื่องมือโดยสรุปจะแสดงเปอร์เซ็นต์การใช้งานสูงสุดในปัจจุบันของคุณ
- การซ้อนทับบนหน้าตามบริบทซึ่งอยู่ติดกับอินพุตแชท
- วิดเจ็ตแคปซูลแบบยุบได้ใน Shadow DOM เพื่อป้องกันความขัดแย้งของสไตล์หน้าโฮสต์
- การตรวจสอบความจุตามเซสชัน (5 ชั่วโมง) และรายสัปดาห์ (7 วัน)
- การนับถอยหลังสดแสดงอย่างแม่นยำเมื่อขีดจำกัดของคุณจะถูกรีเซ็ต
- ปุ่มรีเฟรชตามต้องการและการซิงค์พื้นหลังอัตโนมัติทุกๆ 5 นาที
- ส่วนตัว 100%: อ่านโดยตรงจากเซสชันเบราว์เซอร์ที่ได้รับการรับรองความถูกต้องของคุณเอง

เหตุใดผู้ใช้จึงเลือก AI Use Tracker:
- สำรวจการใช้งานอัตโนมัติที่รวดเร็วโดยไม่ต้องโหลดหน้าซ้ำด้วยตนเอง
- Cleaner UI ที่ผสานรวมกับอินเทอร์เฟซการแชท AI ได้อย่างราบรื่น
- อัตราจังหวะที่ดีขึ้นสำหรับการเขียนโค้ด การเรียนรู้ หรือการเขียนอย่างหนัก
- ปลอดภัยด้วยการออกแบบที่ไม่มีเซิร์ฟเวอร์ภายนอก ไม่มีการติดตาม และไม่มีการวัดและส่งข้อมูลทางไกล
- การควบคุมแผงด้านข้างที่เรียบง่ายพร้อมตัวเลือกเปิด/ปิดอย่างรวดเร็ว

เหมาะสำหรับ:
- นักพัฒนาและผู้ใช้ระดับสูงที่ใช้ Claude Code หรือ ChatGPT มีข้อจำกัดอย่างมาก
- สมาชิกแผน Plus, Pro และ Team ที่ต้องการอ่านโควต้าที่ชัดเจน
- ผู้เชี่ยวชาญและนักศึกษาที่ต้องการหลีกเลี่ยงการขัดจังหวะขั้นตอนการทำงานเชิงลึกของตน
- ใครก็ตามที่เบื่อกับการกดปุ่ม "คุณถึงขีดจำกัดแล้ว" โดยไม่มีการเตือนล่วงหน้า

รหัสที่มา: https://github.com/cupcakedev/ai-usage-extension

## คำหลัก

การใช้งาน claude, ขีดจำกัด claude, ขีดจำกัด chatgpt, การใช้ codex, ตัวติดตามการใช้งาน ai, ตัวติดตามขีดจำกัดอัตรา, รีเซ็ต claude, โควต้า chatgpt, การใช้งาน openai, ประสิทธิภาพการทำงาน

## จุดประสงค์เดียว

แสดงเซสชันและขีดจำกัดการใช้งานรายสัปดาห์สำหรับบัญชี Claude และ ChatGPT/Codex ของผู้ใช้ที่ลงชื่อเข้าใช้ในป๊อปอัปส่วนขยาย ป้ายแถบเครื่องมือ และการซ้อนทับหน้าผู้ให้บริการ

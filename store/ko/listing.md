# Chrome 웹 스토어 목록 - 영어

## 이름

AI 사용량 추적기: Claude, Codex의 할당량 및 한도

## 간단한 설명

팝업과 페이지 오버레이를 통해 Claude 및 ChatGPT(Codex) 세션과 주간 사용 한도를 한눈에 추적할 수 있습니다. 개인정보 보호를 최우선으로 하며 설정이 필요하지 않습니다.

## 전체 설명

AI 사용 추적기: Claude를 위한 할당량 및 제한, Codex는 보다 명확하고 예측 가능한 AI 보조 경험을 원하는 사람들을 위한 브라우저 확장입니다. 메시지 제한을 추적하고, 실시간 카운트다운을 확인하고, 공급자 페이지에 눈에 띄지 않는 사용량 측정기를 직접 표시하여 갑작스러운 제한에 도달하지 않고 작업에 집중할 수 있습니다.

코딩, 글쓰기, 연구 또는 심층적인 문제 해결을 위해 Claude 및 ChatGPT를 사용하든 AI Usage Tracker는 제한 블록에 부딪히는 마찰을 줄이는 데 도움이 되며 용량 모니터링 방법을 직접 제어할 수 있습니다. 오버레이가 표시되는 위치와 한도를 추적하는 방법을 선택합니다.

AI Usage Tracker는 Kimi, MiniMax, Cursor 및 Xiaomi MiMo도 지원합니다. 각 공급자의 계정 데이터에 따라 세션, 주간, 계획, 모델, 잔액 및 재설정 시간 세부 정보를 표면화할 수 있습니다. API 키나 별도의 로그인이 필요하지 않습니다. 확장 프로그램은 브라우저의 이미 인증된 공급자 세션에서만 읽습니다.

주요 기능:

- Claude(claude.ai) 및 ChatGPT/Codex(chatgpt.com)에 대한 실시간 제한 추적
- 현재 가장 높은 사용률을 보여주는 한눈에 볼 수 있는 도구 모음 배지
- 채팅 입력 바로 옆에 위치하는 상황별 페이지 오버레이
- 호스트 페이지 스타일 충돌을 방지하기 위해 Shadow DOM의 축소 가능한 캡슐 위젯
- 세션 기반(5시간) 및 주간(7일) 용량 모니터링
- 한도가 재설정되는 시기를 정확하게 보여주는 실시간 카운트다운
- 주문형 새로 고침 버튼 및 5분마다 자동 백그라운드 동기화
- 100% 비공개: 인증된 브라우저 세션에서 직접 읽습니다.

사용자가 AI Usage Tracker를 선택하는 이유:
- 수동으로 페이지를 다시 로드할 필요 없이 빠르고 자동화된 사용량 폴링
- AI 채팅 인터페이스와 완벽하게 통합되는 더욱 깔끔한 UI
- 어려운 코딩, 학습 또는 쓰기 세션을 위한 더 나은 속도
- 외부 서버, 추적, 원격 측정이 없어 안전하게 설계되었습니다.
- 빠른 활성화/비활성화 옵션을 갖춘 간단한 측면 패널 컨트롤

다음에 적합합니다:
- Claude Code 또는 ChatGPT 제한을 많이 사용하는 개발자 및 고급 사용자
- 자신의 할당량을 명확하게 확인하고 싶은 Plus, Pro, Team 요금제 가입자
- 깊은 작업 흐름을 방해하지 않으려는 전문가 및 학생
- 사전 경고 없이 '한계에 도달했습니다'에 지친 분

소스 코드: https://github.com/cupcakedev/ai-usage-extension

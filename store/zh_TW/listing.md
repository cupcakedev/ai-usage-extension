# Chrome 線上應用程式商店清單 - 英語

## 姓名

AI 使用追蹤器：Claude、Codex 的配額和限制

## 簡短描述

在彈出視窗和頁面疊加中一目了然地追蹤 Claude 和 ChatGPT (Codex) 會話以及每週使用限制。隱私第一，無需設定。

## 完整描述

AI 使用追蹤器：Claude 的配額和限制，Codex 是一個瀏覽器擴展，適合想要更清晰、更可預測的 AI 助理體驗的人。追蹤您的訊息限制，查看即時倒數計時，並直接在提供者頁面上顯示不顯眼的使用量表，以便您可以專注於您的工作，而不會遇到突然的限制。

無論您使用 Claude 和 ChatGPT 進行編碼、寫作、研究還是深入解決問題，AI 使用情況追蹤器都有助於減少達到限制塊的摩擦，並讓您可以直接控制容量的監控方式。您可以選擇疊加層的顯示位置以及追蹤限制的方式。

AI 使用追蹤器還支援 Kimi、MiniMax、Cursor 和小米 MiMo。根據每個提供者的帳戶數據，它可以顯示會話、每週、計劃、模型、餘額和重置時間詳細資訊。不需要 API 金鑰或單獨登入：擴充功能僅從瀏覽器已經經過驗證的提供者會話中讀取。

主要特點：

- Claude (claude.ai) 和 ChatGPT/Codex (chatgpt.com) 的即時限制跟踪
- 一目了然的工具列徽章顯示您目前的最高使用百分比
- 上下文頁面疊加位於聊天輸入旁邊
- Shadow DOM 中的可折疊膠囊小工具可防止主機頁面樣式衝突
- 基於會話（5 小時）和每週（7 天）的容量監控
- 即時倒數準確顯示您的限制何時重置
- 按需刷新按鈕和每 5 分鐘自動後台同步
- 100% 私密：直接從您自己經過身份驗證的瀏覽器會話讀取

使用者為何選擇 AI 使用追蹤器：
- 快速、自動的使用情況輪詢，無需手動重新載入頁面
- 更乾淨的用戶介面，與人工智慧聊天介面無縫集成
- 為繁重的編碼、學習或寫作課程提供更好的節奏
- 設計安全，無外部伺服器、無追蹤、無遙測
- 簡單的側面板控制，帶有快速啟用/停用選項

非常適合：
- 使用 Claude Code 或 ChatGPT 的開發人員和進階使用者受到嚴重限制
- 希望清楚了解其配額的 Plus、Pro 和 Team 計劃訂閱者
- 想要避免中斷深度工作流程的專業人士和學生
- 任何厭倦在沒有事先警告的情況下說「你已經達到極限」的人
